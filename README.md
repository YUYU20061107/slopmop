# SlopMop

**Mop up the AI slop. An agent skill that turns “make it look better” into dispatchable commands, measurable acceptance checks, and a construction gate.**

`SlopMop`（仓库名 `slopmop`）是一个给 AI 编程/设计代理用的前端质感技能包：派前端活时把 `SKILL.md` 附在任务里，用命令词点名要落实的效果，执行方按词条的「诊断—动作—禁令—验收—交棒」施工，交付时逐条标注「已落实 / 不适用（原因）」。

主要场景：业务操作型界面（Operate：后台、工具、业务系统）的精修与局部改造。它管机械层（不犯低级错误）与已命名的效果，不管品牌方向——方向由你的项目 brief 决定。

## 12 个命令词

| 命令 | 解决什么 |
|---|---|
| `deslop` | 去 AI 味清扫：删渐变发光、主色降饱和、微文案去情绪化，末道灰度校验 |
| `space` | 间距与分组：8px 网格、规范值序列、标题上下距归属 |
| `layer` | 微对比色阶分层：相邻层级明度差 1%~3%，删边框后层级仍可辨 |
| `type` | 排印与数字稳定：动态数字等宽锁宽、正文行宽 65–75ch |
| `motion` | 动效分性格：功能干脆到位、情绪才许回弹、全页一个 authored moment |
| `feedback` | 完成反馈：关键动作 0.5 秒内可判成败，失败路径单独验 |
| `linkage` | 状态联动：先列「状态源 → 受影响呈现」清单再实现 |
| `tactile` | 物理感交互：叠卡展开 / 吸附画线 / 惯性滚轮，精确点选不让位 |
| `spread` | 圆形扩散转场：从点击位置扩散，低性能自动降级 |
| `nav` | 导航选型：六式选一不混搭，交付须写明所选式与场景依据 |
| `polish` | 末轮分诊精修：状态 → 主路径 → 机械地板 → 点名词条，留对照图 |
| `audit` | 只审不改：五维问题清单 P0–P3 分级，整体判断与机械核查分开写 |

## 方法骨架

- **量化阈值总表**：每条阈值都标注来源与适用边界；标「经验值」者为来源方口径、未经独立验证，只能作验收参考线，不冒充行业标准；标「仅深色」者禁止用于亮色项目。
- **施工闸门（四步）**：报告（阴性信息先行）→ 确认 → 最小改动 → 复测对比；低/中/高三档风险分级，高风险（换主色体系、整页重做）必须由项目所有者本人拍板。
- **证据分级**：实测（渲染/截图/脚本核查）＞ 执行者自报 ＞ 经验口径，不得跨级引用。

## 使用方式

把 `SKILL.md` 附在你给代理的任务说明里，点名本轮词条即可，例如：

> 本轮执行 `deslop`、`space`、`type` 三条，模式 Operate；按第四节施工闸门：先交短报告，我确认后再动，交付逐条标注落实情况并附同视口对照图。
